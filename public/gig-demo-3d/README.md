# Concert demo assets

All files in `assets-manifest.json` are redistributed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The manifest records
each file's author, source, size and SHA-256 checksum.

| Files | Creator and original source |
| --- | --- |
| `casual.glb`, `punk.glb`, `suit.glb` | Quaternius, [Ultimate Modular Men](https://quaternius.com/packs/ultimatemodularcharacters.html) |
| `wood_floor_worn_*.jpg` | Dimitrios Savva, [Wood Floor Worn / Poly Haven](https://polyhaven.com/a/wood_floor_worn) |
| `brick_wall_001_*.jpg` | Dimitrios Savva and Rob Tuytel, [Brick Wall 001 / Poly Haven](https://polyhaven.com/a/brick_wall_001) |

The unmodified GLB exports were obtained from the Liminal repository. Its
[asset inventory](https://github.com/yerdaulet-damir/liminal/blob/main/assets-manifest.json)
and [provenance notes](https://github.com/yerdaulet-damir/liminal/blob/main/ASSETS.md)
identify them as Quaternius CC0 assets. They contain four skinned modular body
parts and no animation clips. Material adjustments and skeletal performance
poses are applied in application code.

Texture maps are original 1024×1024 JPEGs, using the OpenGL normal convention.
[Poly Haven's asset licence](https://polyhaven.com/license) permits use and
redistribution under CC0. The application also reuses the repository's existing
speaker grille image. Stage geometry, instruments, labels and animation code
were authored for this demo.
