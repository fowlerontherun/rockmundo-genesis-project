# Top of the Pops admin demo access

The Top of the Pops administration route is `/admin/top-of-the-pops`.

It is exposed from **Admin → Events & Competitions → Top of the Pops / Demo**.

The page contains the safe admin demo harness. **Launch Top of the Pops demo** builds a dry-run lineup from the current UK chart snapshot. Selecting an act and choosing **Run full demo lifecycle** opens the accelerated invitation-to-broadcast simulation using the real TOTP 3D broadcast viewer. Demo mode does not write player progression or rewards.
