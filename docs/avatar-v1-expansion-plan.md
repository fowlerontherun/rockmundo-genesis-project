# Avatar V1 expansion plan

Avatar V1 is the only production avatar system going forward.

## Phase 1 — reliability and attachment polish

- Audit glasses, earrings, hats, facial hair and tattoo anchors on masculine and feminine frames.
- Add independent left/right earring control.
- Prevent accessory floating, clipping and invalid saved combinations.
- Keep one shared appearance contract across creator, profiles and gigs.

## Phase 2 — visual quality

- Improve V1 skin, hair, eye and fabric materials.
- Add higher-quality close-up texture/detail settings while retaining lower-cost crowd rendering.
- Improve existing clothing silhouettes and curated pack presentation rather than replacing the skeleton.

## Phase 3 — variety

- Expand hairstyles, facial hair, face details, accessories and curated clothing packs.
- Preserve existing catalogue IDs, purchases, equipped items and stat/XP bonuses.

## Phase 4 — performance

- Expand instrument-specific stage poses and animation variation on the V1 skeleton.
- Improve close-up gig camera results, hand placement and facial performance without adding a second avatar runtime.

## Release gate

Every avatar change must render correctly in the avatar editor, player profile, 3D gigs and Top of the Pops before release.
