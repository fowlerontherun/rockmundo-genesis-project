# Avatar V2 Phase 1 — two genuine fitted, fully skinned production body rigs

**State:** Phase 1 *authoring and fail-closed evidence pipeline*. No uploaded source,
generated guide, initial bone-heat bind or JSON-only test counts as an approved body.
Current production registry remains planned; V1 and the existing gig pipeline stay live.

This phase uses the pinned **Blender Human Base Meshes v1.4.1 (CC0)** official
masculine and feminine stylised meshes already generated by
`.github/workflows/avatar-v2-real-source-seeds.yml`. It does not manufacture
substitute mannequin geometry or convert the preliminary head-turn experiment.

## 1. Fit and save each real body independently

Download the two latest authoring-only workflow artifact packs. Preserve
provenance, original source `.blend`, guide and contact views separately.

For each frame:

1. Open `<frame>-joint-handles.blend` in Blender 4.3+.
2. Fit **all** `RMV2_FIT__*` empties to real shoulder, clavicle, spine, elbow,
   wrist, every finger segment, pelvis, knee, ankle, toe, actual jaw hinge,
   measured eye-sphere centres and independently measured earlobe attachment
   positions. The auto-created handles are *not* fitted.
3. Save a frame-specific reviewed source. Apply artist-reviewed handles:

```bash
blender work/masculine-joint-handles-reviewed.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_fit_rig.py -- \
  --mode apply --reviewed \
  --report work/phase1/masculine/masculine-joint-fit.json \
  --output work/phase1/masculine/masculine-fitted.blend

blender work/feminine-joint-handles-reviewed.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_fit_rig.py -- \
  --mode apply --reviewed \
  --report work/phase1/feminine/feminine-joint-fit.json \
  --output work/phase1/feminine/feminine-fitted.blend
```

An unmodified guide will fail the moved-landmark and anatomical sanity checks.
The fitted rest pose must retain correct parentage for jaw, both eyes and
non-deforming independent ear anchors. The six upper-arm, forearm and thigh
twist helpers are recomputed from the fitted long bones.

## 2. Start real skinning, without overwriting authored weights

Find the unique *continuous source body object name* in each Blender scene;
use that exact name for `--body`. Run this once per fitted frame:

```bash
blender work/phase1/masculine/masculine-fitted.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_phase1_body.py -- \
  --mode prepare --frame masculine --body "ACTUAL_MASCULINE_BODY_OBJECT" \
  --output-root work/phase1

blender work/phase1/feminine/feminine-fitted.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_phase1_body.py -- \
  --mode prepare --frame feminine --body "ACTUAL_FEMININE_BODY_OBJECT" \
  --output-root work/phase1
```

This creates distinct **INITIAL-BIND-needs-repaint.blend** files, plus
`phase1-initial-bind-report.json` per frame. Blender's genuine bone-heat
initial binding is four-influence-normalised, with cautious region-local
twist distribution; it retains real source materials and UVs, partitions
existing continuous body polygons into eight independently tagged skin
regions and rigidly skins the **actual** measured left/right source eyeballs.
It will not replace pre-existing artist skinning. It does not set an
`artist-approved` or `validated` flag and deliberately leaves zero-heat
or absent finger influences as explicit QA blockers.

## 3. Manually finish both bodies

Open both initial-bound scenes interactively. Paint every region against the
fitted skeletal anatomy; specifically refine shoulder/clavicle, elbow creases,
wrist axial roll, glute/hip, knees, ankles/forefoot and all 30 finger joints.
Verify each of the six twist helpers has genuine skin influence and smoothly
distributes axial roll. Do not assign arbitrary tiny weights just to pass a
counter. Keep a maximum of four meaningful deform influences per vertex.

Sculpt **actual**, separate, non-zero pose-corrective shape keys on the same
body for `poseShoulderLeft/Right`, `poseElbowLeft/Right`,
`poseHipLeft/Right` and `poseKneeLeft/Right`; inspect them at the
corresponding extreme joint angle. Keep the complete eight original
`rockmundoBodyRegion` material tags on used polygons. Keep authored source
PBR textures, UVs and facial landmarks intact. Save an editable
`<frame>-phase1-artist-cleaned.blend` for each frame; initial scene files
must remain untouched as provenance.

## 4. Audit **deformation**, not just the skeleton names

Run both independently on the cleaned scenes, still outside
`public/avatar-v2`:

```bash
blender work/phase1/masculine/masculine-phase1-artist-cleaned.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_phase1_body.py -- \
  --mode assess --frame masculine --body "ACTUAL_MASCULINE_BODY_OBJECT" \
  --output-root work/phase1

blender work/phase1/feminine/feminine-phase1-artist-cleaned.blend --background \
  --python scripts/avatar-v2/blender/rockmundo_avatar_v2_phase1_body.py -- \
  --mode assess --frame feminine --body "ACTUAL_FEMININE_BODY_OBJECT" \
  --output-root work/phase1
```

The assessment fails if a rig lacks its reviewed joint-fit report; if any
deform bone is unused; if any body vertex has zero or over-four influences or
non-normalised weights; if an original eye is not bound; if one of eight
occlusion regions is empty; if any of the eight **authored** correction targets
has less than 0.5mm of meaningful displacement; or if any tracked joint
does not visibly displace its real skinned vertices during its QA pose.

The deterministic pose suite covers symmetric raised reach, elbow fold,
wrist roll, deep crouch, seated drums, ankles/toe flex, all-finger instrument
grips and torso twist. Per-pose displacement in millimetres is recorded in
`<frame>-phase1-assessment.json`. Failing reports are saved to disk but do
not export a candidate. Passing assessments capture **seven real Workbench
contact views**, an editable assessed Blender scene and one
`<frame>-PHASE1-BODY-CANDIDATE-not-validated.glb`; that GLB is immediately
read back and every actual BIN skin/weight accessor is validated.

## Phase 1 exit / handoff boundary

| Evidence per frame | Automated | Human review |
|---|---|---|
| Pinned genuine source, fitted full skeleton and joint report | preflight | anatomical bone centres |
| Body + true bilateral eye skinning, complete finger/twist chains | strict weight audit | gradient quality and natural shape |
| Eight full-body used skin occlusion regions | material/geometry audit | boundaries and UV/material look |
| Eight sculpted shoulder/elbow/hip/knee corrective keys | non-trivial geometry audit | crease, fold, silhouette |
| Reach, fold, wrist, crouch, seated drums, foot, fingers, torso | deterministic evaluated-mesh checks | clipping, implausible twisting, artist stage poses |
| Real front, side, back and extreme contact views | generated only on passing candidate | independent recorded sign-off |
| Actual skinned candidate GLB | byte-accurate BIN integrity check | close-up visuals, topology, compatibility |

**No Phase 1 production approval** until *both* frame-specific reviewed
`.blend` files, fit reports, passing weight and deformation reports, all
pose captures and SHA-256-bound candidate GLBs exist **and** an independent
artist has approved actual joint fit, skin folds, penetration and symmetry.

The Phase 1 GLBs are **authoring candidates, not release files**: the normal
LOD0/LOD1 exporter intentionally also requires subsequent Phase 2 sculpt/
facial shapes, surfaces and Phase 4 authored LODs. Do not put these candidates
into the runtime manifest, release wardrobe, admin promotion queue or player/
gig appearance snapshots yet. Phase 3 garment weight transfer must start only
from the approved and fitted *matching frame*.

The dedicated `avatar-v2-phase1-body.yml` CI runs the reproducible shared
contract, joint-fit and real binary regressions without falsely claiming
that CI has visually inspected either Blender source. Use the two detailed
per-frame reports and the separate source workflow for full asset evidence.

## Continued Phase 1: live-pose-equivalent corrective and real-source experimental proof

The `--mode assess` path now drives **exactly the same joint-angle
thresholds and smoothstep weights as the live Three.js pose-corrective
controller**, rather than merely checking the names of shape keys.
It measures **actual evaluated geometry differences before and after
applying the correction shapes** at reach, elbow fold, crouch and seated
drumming angles. The body fails assessment if the correction is absent
where the game would activate it. All 30 finger-segment groups are now
observed independently during the instrument-grip proof, and the body
weight audit rejects token-weighted fingers/twist regions and accidental
weights on undeclared deforming bones. Existing genuine CC0 source
landmark groups are reported without treating them as skin bones.

Both frame-specific passing candidates get 12 Workbench proof views:
three neutral anatomical angles, eight distinct extreme poses and a
dedicated hand/finger grip close-up. The captures actually apply the
correction targets with live-equivalent weights. They are still
**deformation diagnostics**, not an autonomous visual fit approval.

The real-source GitHub Actions workflow additionally attempts an
**explicitly unreviewed, non-production initial heat-binding experiment**
on each actual official CC0 source guide. These probes are intentionally
isolated from the `--mode prepare` production candidate contract:
an unfitted guide must *always* fail the reviewed-fit preflight.
The experiment can save a genuine Blender working scene, a limited
pose contact gallery, a read-only skin audit, and—only if raw weight
integrity allows it—a binary-inspected source-only GLB. It emits clear
blocking reasons when a joint's auto weights, body-region coverage or
binary export fail. Results are separately uploaded for 14 days in the
`avatar-v2-phase1-UNFITTED-diagnostics` GitHub Actions artifact.
Blender probe failures are deliberately non-gating while initial
unfitted artist sources are under review; the script still saves per-frame
diagnostics and the separate existing source/GLB production-boundary
checks remain required.

Neither experimental result can replace the two artist-fitted and
manually cleaned body scenes, deformation correction sculpts or
independent sign-off tracked in [Phase 1 issue #2197](https://github.com/fowlerontherun/rockmundo-genesis-project/issues/2197).
