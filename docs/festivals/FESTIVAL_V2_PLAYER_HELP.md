# Festival V2 — visitor help

This is the short player-facing help for a festival visitor. The festival's
**Grounds** tab also has an accessible *About live festival updates and
accessibility* help section and an **Open published timetable** button.

## Finding your way around

1. Open **World → Festivals** (`/world/festivals`) and choose a festival.
2. The **Timetable** shows announced artists and planned local set times; a
   scheduled time **does not mean** an act has started playing.
3. In **Grounds**, select a stage to see announced performers. The illustrated
   layout shows stage identities, **not** real walking directions or a site map.
4. On a slow phone, use **Lightweight stage view**. It works without the 3D
   graphics and can be used with keyboard, touch and reduced motion enabled.
5. When published, read the organiser's **Travel & arrival** and **Accessibility**
   information before making a real journey.

## Live updates and tickets

- **Official festival updates** show only confirmed, public edition events.
  A timetable, seasonal outlook or empty crowd display is **not** proof of a
  current performance or an empty venue.
- If you see **stale**, **unavailable** or **no verified live status**, use
  **Retry live festival updates**. The published timetable remains available.
- In **Tickets**, select the correct character and wait for wallet verification.
  If verification fails, use Retry; don't buy another ticket just because the
  wallet could not load.
- If a festival is **cancelled**, the old programme is historical. It does not
  mean the artists are currently performing. Check official ticket/refund
  messages; do not infer a refund from a status banner alone.
- If a festival's detail page fails, try **Retry festival details** or return
  to **Browse other festivals** (`/world/festivals`).

## For organisers and support

Stage and crowd information is a privacy-filtered snapshot of the canonical
festival runtime. It never gives the public backstage permissions, exact crowd
headcounts or private incident details. Report an apparently wrong stage,
ticket or festival day with the page route and approximate local time; do not
share passwords, access tokens or private player identifiers.
